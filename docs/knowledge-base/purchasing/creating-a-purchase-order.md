# Creating a draft Purchase Order

Users with Purchase Order create access can start a draft from an approved supplier recommendation at Purchase Orders → Create Draft PO. Search by PR reference, supplier, or quote reference and use the page controls to find additional recommendations. The selected recommendation shows its supplier, amount, and expected delivery date.

The lookup is limited to the current authorized company and location. Creating the draft performs a final server check; a recommendation that was approved, used, or changed by another user may be rejected and should be refreshed before retrying. Receiving remains a separate action and does not occur when the draft is created.
