# Reviewing a user’s assigned scopes

Choose `Scopes` on User Access, then use Assigned Scopes to search by scope name or code and filter by Company, Brand, Location, Department, or Project. Results are limited to the selected company and paginated by the server; foreign or unknown scope records are not shown. Scope data is not loaded for Roles, role Requests, or Audit. Location assignment controls appear only in this section. Scope assignment and deactivation still perform their own live authorization and audit checks.

Search, filters, paging, and `Open scope controls` preserve the Scopes section and the current register context. If a selected scope is no longer on the filtered page, the screen keeps the action unavailable until the register is refreshed.
