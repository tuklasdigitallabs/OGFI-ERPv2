# Reviewing a user’s assigned roles

On User Access, search Assigned Roles by role name or code. The list is paginated and shows role status and assignment start time. Paging only changes the view; effective permissions continue to reflect all active authorized roles. Use the role link for permission detail, and use the existing controlled action to deactivate a role when permitted.

Choose `Roles` on User Access to review assigned roles and the role assignment catalog. Overview also shows the role and effective-permission summary. Other sections show an unavailable marker for those counts because their detail reads are not loaded there. The role catalog is loaded only for Roles and, when selected, role Requests; role assignment remains server-authorized and audited.
