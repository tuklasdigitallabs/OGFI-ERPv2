# Reviewing role assignments

On a role’s access page, use Assigned Users search to find active assignments by name or email. Results are paginated, and each user shows only a bounded preview of active scopes; open the user record for authoritative scope detail.

The Role Permissions matrix is also paginated and searchable. Use the Sensitive, Overrides, or Recommended Drift filters to narrow review. Saving from a filtered page preserves enabled permissions that are not visible on that page; role permission changes still require the existing controlled reason, authorization, MFA, and audit process.
