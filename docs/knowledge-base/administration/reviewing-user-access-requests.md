# Reviewing User Access requests

Open a user’s User Access page and choose the `Requests` section. Select `Scope requests` or `Role requests`; only the selected request kind is loaded. Use the status filter and server pagination to find a request, then choose `Open review controls` on a pending row.

The selected-request composer shows the target user, requester, selected company, requested scope or role, status, risk, and pending-only reason or evidence context. Approve or reject with the required review reason. The server rechecks current authority, target membership, pending status, and segregation rules; a stale or historical request is read-only. Completed decisions remain auditable and cannot be changed from this screen.
