# Reviewing User Access audit history

Choose the `Audit` section on a user’s User Access page to review that user’s controlled actions in the selected company. The list is read-only, searchable, server-paginated, and limited by the user’s exact actor identity; a name search never selects another user.

Sensitive contact, network, credential, token, storage, and evidence-link fields are redacted. Choose `Open audit detail` for the separately authorized event record. A missing, foreign, or unavailable event is not disclosed.
