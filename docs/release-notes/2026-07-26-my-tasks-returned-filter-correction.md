# OGFI ERP Release Notes — My Tasks returned-work filter correction

**Release date:** July 26, 2026  
**Audience:** Branch Operations and Food Safety users  
**Affected locations / roles:** Authorized record creators and reviewers in the selected branch scope  

## What changed

- Users who can correct returned Branch Operations checklists or Food Safety
  logs can filter My Tasks to `RETURNED` without valid correction work
  disappearing.

## What you need to do

- No action is required. Use the existing Module and Status filters in My Tasks.

## Important notes

- Review-only users continue to see only review work.
- My Tasks does not grant action authority. Opening a task still uses the source
  workspace's current permission, scope, status, and actor checks.

## Learn more

- `docs/knowledge-base/getting-started/understanding-the-dashboard-my-tasks-and-notifications.md`

## Support

Report unexpected missing work through the normal OGFI ERP support channel and
include the selected company, location, module, and status filter.
