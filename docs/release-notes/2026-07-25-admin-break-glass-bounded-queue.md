# Break-Glass register bounded queue

The Break-Glass Access register now provides server-owned paging and filters for status, reason/evidence, target user, and location. Open one grant to review its emergency-access context and use the selected-record action sheet for approval, rejection, revocation, or post-review. Target catalogs are bounded and the request action explains when refinement is required.

Existing privileged MFA, no-self-approval/review, expiry, audit, scope, and session invalidation controls remain enforced by the server.
