# OGFI ERP Release Notes — Inventory Control Pilot Navigation

**Release date:** July 30, 2026
**Audience:** Pilot users, Branch Managers, Warehouse and Storekeeper staff, Purchasing staff, Accounting reviewers, Operations Managers, and System Administrators
**Affected locations / roles:** Authorized users in an environment configured for the Inventory Control Pilot

## What Changed

- The page header now shows `Inventory Control Pilot` when that release profile is active.
- Work Management, Restaurant Operations, Workforce, Marketing, Expansion, and Finance sections and destinations shown to an authorized user carry a visible `Deferred` marker because they are outside the current pilot release scope.
- Deferred destinations remain in navigation when the user's existing access allows them. The marker does not grant new access, remove existing safe authority, or replace server checks on direct routes, actions, records, approvals, exports, or evidence.

## What You Need To Do

- Confirm the company, brand, and location in the header before working.
- Use only the approved pilot locations, items, users, and connected inventory-control workflows.
- Treat a `Deferred` destination as outside the pilot release scope even if you already have authority to open or safely use it.
- Report a missing or incorrect marker, unexpected destination, unsafe enabled action, or missing required pilot workflow to the system administrator and pilot release owner.

## Important Notes

- The pilot badge is not a production GO decision. The pilot remains test-data or shadow UAT until exact-candidate technical gates, recovery evidence, human UAT, and named release approval pass.
- Navigation visibility does not change permissions. Users still see and access only the destinations, records, and actions permitted by their existing role and scope.
- A deferred module is not pilot-ready or production-ready merely because it is visible or contains safe working behavior.
- A stock variance is an investigation signal, not proof of theft or misconduct.
