# OGFI ERP Release Notes — Food Safety dashboard profiles

**Release date:** July 26, 2026

**Audience:** Branch Managers, Branch Supervisors, Food Safety staff, and Operations Managers

**Affected locations / roles:** Users with Food Safety view access in the selected company and location

## What Changed

- `Food Safety Exceptions` now opens a read-only, selected-scope profile. The card counts exception readings across scoped history, and the destination separately shows how many logs are affected.
- `Food Safety Reviews` now opens a read-only profile of all scoped logs in `SUBMITTED` or `EXCEPTION REVIEW`; it is not a personal task list.
- Search can narrow either profile without accepting raw status, log type, or business-date values that would redefine it. Record and export controls remain hidden in these views.
- Unsupported or retired profile links fail visibly, and log detail retains the return path to the same profile, search, and page.

## What You Need To Do

- No action is required. Use the two Overview cards for Food Safety oversight, and use `My Tasks` for enrolled work you may be able to act on.

## Important Notes

- Exception readings are historical facts included by the profile; the count does not mean they are currently open or unresolved.
- These profiles and their source links do not grant review, correction, or closure authority. Log detail independently rechecks current permission, scope, status, actor lineage, and segregation rules.
- The change does not create Incident records, post Wastage or inventory movements, or change stock.
- This note describes confirmed behavior only; it does not declare the wider Food Safety workspace or release production-ready.
