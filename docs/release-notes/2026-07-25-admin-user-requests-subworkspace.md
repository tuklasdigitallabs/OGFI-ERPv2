# Administration User Access Requests subworkspace

User Access now provides a URL-backed Requests section with separate scope and role request views. Each view is bounded and paginated, and review actions open one selected-request composer instead of repeating approve/reject forms in every row. Historical decisions remain read-only and existing authorization, MFA, segregation, CAS, and audit controls remain authoritative.

PostgreSQL execution, responsive browser, hosted recovery, and UAT evidence remain required before Administration or Phase I completion.
